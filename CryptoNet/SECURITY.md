# Security policy · Kebijakan keamanan

## Reporting a vulnerability

Please report security issues **privately** to Gravicode Studios rather than opening a public issue: use GitHub's
"Report a vulnerability" (private security advisory) on the repository. Include the affected package and version,
a description, and steps or a test that reproduce the problem. We aim to acknowledge reports within 3 working days.

Crypto.Net has not yet had an external audit. Treat it accordingly and see
[docs/en/security.md](docs/en/security.md) for deployment guidance.

## Melaporkan kerentanan

Laporkan masalah keamanan **secara privat** ke Gravicode Studios, bukan lewat issue publik: gunakan fitur
"Report a vulnerability" (private security advisory) GitHub di repositori ini. Sertakan paket dan versi yang
terdampak, deskripsi, serta langkah atau test untuk mereproduksi. Kami berupaya menanggapi dalam 3 hari kerja.

Crypto.Net belum diaudit pihak eksternal. Perlakukan sesuai kondisi itu dan baca
[docs/id/keamanan.md](docs/id/keamanan.md) untuk panduan penerapan.
