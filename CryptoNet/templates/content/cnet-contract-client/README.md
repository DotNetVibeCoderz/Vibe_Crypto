    # CnetContracts

    A console app whose contract clients are generated by `Crypto.Net.Generators` at build time. `Contracts/Erc20.abi.json` becomes the typed class `Erc20` (views, sends, calldata encoders, event records). `Contracts/Counter.idl.json` becomes `CounterProgram` (instruction builders and account decoders). Drop in your own ABI, Hardhat/Foundry artifact or Anchor IDL, then rebuild. To produce a `.cs` file instead, use `cnet gen MyContract.abi.json`.

```bash
dotnet run
```

    ## Configuration

    `appsettings.json` holds a testnet profile. Override any value with an environment variable (`CNET_Network=solana-devnet`),
    a command-line switch (`--Network solana-devnet`) or user secrets. Keep mnemonics out of source:

    ```bash
    dotnet user-secrets set Mnemonic "<your test phrase>"
    export CRYPTONET_DRPC_KEY=...   # optional: dRPC / Ankr keys raise rate limits
    ```

    Documentation: https://github.com/DotNetVibeCoderz/Vibe_Crypto/tree/main/CryptoNet/docs/en
