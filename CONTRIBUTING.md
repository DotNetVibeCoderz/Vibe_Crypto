# Contributing · Berkontribusi

Thank you for helping improve Crypto.Net! Build instructions, test commands and guidelines are in
[docs/en/contributing.md](docs/en/contributing.md).

Terima kasih telah membantu mengembangkan Crypto.Net! Petunjuk build, perintah test dan pedoman ada di
[docs/id/kontribusi.md](docs/id/kontribusi.md).

The short version:

1. `./scripts/build-native.ps1` then `dotnet test tests/Crypto.Net.Tests` must pass.
2. Cryptographic changes come with an official test vector.
3. Update `docs/en` **and** `docs/id`, plus `CHANGELOG.md`, for user-visible changes.
4. Never commit keys, mnemonics or keystores.

Crypto.Net is built by Gravicode Studios, led by Kang Fadhil.
